# Cultura no Tatame — História, Cultura e Conhecimento

Site educativo e interativo do projeto de extensão universitária **Cultura no Tatame**, desenvolvido no curso de **Análise e Desenvolvimento de Sistemas — Universidade Cruzeiro do Sul**, em colaboração planejada com a comunidade do **Projeto Social Vikings Jiu-Jitsu**, no CEU Tremembé.

## Conteúdo

* **História**: viagem interativa por cinco paradas cronológicas.
* **Conheça o Tatame**: cinco posições e técnicas apresentadas conceitualmente.
* **Você Sabia?**: cinco curiosidades sobre faixas, graus, quimono e tradições.
* **Desafio do Conhecimento**: quiz de cinco perguntas, com respostas comentadas e opção de repetir.
* **Nossa Comunidade**: apresentação do Vikings e link para seu Instagram.
* **Fontes e Referências**: links antes do rodapé.

## Como visualizar

Abra `index.html` no navegador. Todos os arquivos de estilo, programação e ilustrações estão dentro desta pasta. A internet é usada somente para baixar fontes opcionais do Google Fonts e para abrir links de referências/Instagram.

Também há uma versão HTML única separada na entrega, para facilitar a prévia.

## Estrutura

```text
index.html
css/styles.css
js/script.js
assets/logo/vikings-jiu-jitsu.png
assets/illustrations/\*.svg
README.md
```

Não usa banco de dados, conta, cookies de rastreamento ou armazenamento de respostas ao quiz.
